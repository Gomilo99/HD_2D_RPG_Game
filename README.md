# HD_2D_RPG_Game

Proyecto de RPG por turnos con estilo HD-2D en Unity (URP). Incluye combate por turnos,
exploración del mundo, economía, progresión, guardado y presets de atmósfera.

## Requisitos
- Unity **6000.3.6f1** (ver `ProjectSettings/ProjectVersion.txt`).
- Paquete **Input System** habilitado.

## Inicio rápido
1. Abre el proyecto desde Unity Hub.
2. Abre la escena `Assets/Game/Scenes/SampleScene.unity`.
3. Presiona **Play** para validar movimiento y base del flujo.
